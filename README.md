# VIBEMP3

Настольный MP3-плеер на Python и pygame — с плавным кроссфейдом между треками, реалтайм-визуализатором, полностью кастомизируемыми темами и памятью всего, что ты в нём настроил.

## Возможности

- **Плавный кроссфейд** между треками — настраиваемая длительность (1–10 сек), двухканальный аудио-движок сводит старый и новый трек внахлёст, а не переключает их резко.
- **Реалтайм-визуализатор** — блочный эквалайзер с FFT-анализом; если музыка на паузе достаточно долго, по столбикам плавно пробегает цветная волна.
- **Свои темы** — редактор тем прямо в приложении: фон, акцент, текст и цвет волны визуализатора настраиваются слайдерами или напрямую в hex (`#RRGGBB`). Темы хранятся как читаемые `.vibetheme`-файлы, которые можно редактировать вручную или обмениваться ими.
- **Тема "Как в Windows"** — приложение следит за системной тёмной/светлой темой и подстраивается само.
- **Метаданные треков** — название, исполнитель и обложка читаются из ID3-тегов (через `mutagen`).
- **Повтор** — трек / плейлист / выключен, три режима по клику.
- **Плейлисты и альбомы** — добавляй музыку папками или отдельными файлами; всё запоминается между запусками, включая громкость и последний открытый плейлист.
- **Свой шрифт и иконки** — интерфейс полностью кастомизируется через `resources/`.

## Установка

### Вариант 1 — готовая сборка

Если у тебя уже есть собранный `VIBEMP3.exe` (см. [Сборка exe](#сборка-exe-windows) ниже) — просто открой папку и запусти `VIBEMP3.exe`. Ничего устанавливать не нужно, кроме [ffmpeg](#ffmpeg) (см. ниже).

### Вариант 2 — из исходников

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

Также потребуется **ffmpeg** — он нужен `pydub` для декодирования mp3.

<a id="ffmpeg"></a>
**Установка ffmpeg:**

| ОС | Команда |
|---|---|
| Windows | `winget install -e --id Gyan.FFmpeg` |
| macOS | `brew install ffmpeg` |
| Linux (Debian/Ubuntu) | `sudo apt install ffmpeg` |

## Запуск

**Windows** — двойной клик по `run.bat` (проверяет зависимости и ffmpeg перед стартом, выводит понятную ошибку, если чего-то не хватает).

**Вручную:**

```bash
python run.py
```

## Управление

| Действие | Как |
|---|---|
| Пауза / воспроизведение | `Space`, кнопка ▶/⏸ |
| Следующий / предыдущий трек | `→` / `←`, кнопки на панели |
| Перемотка | клик или перетаскивание по прогресс-бару |
| Громкость | `↑` / `↓`, колёсико мыши над слайдером, слайдер внизу |
| Повтор (выкл / плейлист / трек) | кнопка **REP** рядом с "След. трек" |
| Добавить папку / файлы | кнопки **+ Папка** / **+ Файлы** |
| Удалить трек из плейлиста | наведи на строку → крестик справа |
| Настройки | кнопка ⚙ |

## Настройка внешнего вида

Открой **Настройки** (⚙ в правом верхнем углу):

- **Язык** — русский / English
- **Тема** — Тёмная / Светлая / Как в Windows
- **Плавный переход** — длительность кроссфейда, 1–10 секунд
- **Создать тему** — свой редактор тем с превью в реальном времени:
  - слайдеры RGB или прямой ввод в hex для фона, акцента, текста и цвета волны визуализатора
  - можно выбрать и отредактировать уже существующую тему
  - сохранённые темы лежат в `themes/*.vibetheme` — обычный текстовый формат, можно редактировать руками или делиться с кем-то

Пример `.vibetheme`-файла:

```ini
# Тема VIBEMP3 — можно редактировать вручную
name = Розовый неон

bg = 18,18,20
accent = 255,60,180
text = 235,235,240
viz_wave = 180,50,255
...
```

## Структура проекта

```
VIBEMP3/
├── run.py                  # точка входа — проверяет зависимости и ffmpeg
├── main.py                 # главный цикл, окно, отрисовка интерфейса
├── audio_engine.py         # воспроизведение, кроссфейд, метаданные (ID3)
├── visualizer.py           # FFT-эквалайзер и "АФК-волна"
├── ui.py                   # базовые виджеты (кнопки, слайдеры, список треков)
├── settings.py             # настройки приложения + persistence (settings.json)
├── settings_panel.py       # окно настроек, редактор тем
├── custom_themes.py        # формат .vibetheme, чтение/запись
├── theme_transition.py     # плавная анимация смены темы
├── albums.py                # управление плейлистами/альбомами
├── app_font.py              # загрузка кастомного шрифта с фолбэком
├── button_icons.py         # PNG/WEBP-иконки кнопок под тему
├── logo_theme.py            # адаптация логотипа под тёмную/светлую тему
├── resources/
│   ├── font/                 # Bildungswirkung-Regular.otf
│   ├── ui/                   # иконки кнопок (play/pause/next/settings)
│   └── logo/                 # логотип и .ico приложения
├── themes/                  # сохранённые пользовательские темы (.vibetheme)
├── requirements.txt
├── vibemp3.spec              # конфиг для сборки в exe (PyInstaller)
└── build.bat                 # сборка exe одной командой
```

## Сборка exe (Windows)

```bash
pip install -r requirements-build.txt
build.bat
```

Готовая сборка появится в `dist/VIBEMP3/` — папка с `VIBEMP3.exe` и скопированными рядом `resources/`, `themes/`, `settings.json`. Всю папку можно перенести на другой компьютер и запустить без установленного Python (ffmpeg на целевой машине всё ещё нужен отдельно).

Сборка через `--onedir` (папка, а не однофайловый exe) — специально, чтобы ресурсы лежали рядом с exe открыто и их можно было менять без пересборки.

## Требования

- Python 3.10+
- ffmpeg в `PATH`
- Windows (тема "Как в Windows" и .ico-иконка — Windows-специфичные; в остальном плеер использует кроссплатформенный pygame)

## Зависимости

| Пакет | Назначение |
|---|---|
| `pygame` | окно, звук, отрисовка |
| `pydub` | декодирование mp3 через ffmpeg |
| `numpy` | FFT для визуализатора |
| `Pillow` | загрузка .ico/.webp, генерация светлой версии логотипа |
| `mutagen` | чтение ID3-метаданных (название/исполнитель/обложка) |
